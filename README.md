# OpenStation Market Apps

Официальный репозиторий приложений и APK-каталога для **OpenStation Market**, встроенного в прошивку **OpenStation Max** (Яндекс Станция Макс).

- **Основной JSON каталога:** [`catalog.json`](https://raw.githubusercontent.com/Olegu621/openstation-market-apps/main/catalog.json) (41 приложений, без дублей package ID)
- **Полный архивный JSON (включая `-NoUpd` / beta варианты):** [`catalog-all.json`](https://raw.githubusercontent.com/Olegu621/openstation-market-apps/main/catalog-all.json) (44 сборок)
- **Бинарные APK-файлы:** [GitHub Release `apps-v1`](https://github.com/Olegu621/openstation-market-apps/releases/tag/apps-v1)
- **Источник исходной подборки (YaOS):** [Публикация на Дзене](https://dzen.ru/a/aQnQQMeD1Tf7CtBZ) и архив Яндекс Диска

## Как использовать в OpenStation Market

В прошивке **OpenStation Max v1.4.0+** этот каталог уже прописан по умолчанию.
Если нужно указать URL вручную на вкладке **Настройки** в Маркете:

```
https://raw.githubusercontent.com/Olegu621/openstation-market-apps/main/catalog.json
```

## Проверка целостности

Каждый APK в `catalog.json` сопровождается точным `sha256` и `sizeBytes`. OpenStation Market проверяет SHA-256 загруженного файла перед запуском установки через `openstationd`.
